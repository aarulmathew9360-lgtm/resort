# 🌲 Nilgiri Mist Luxury Resort & Wellness Retreat, Ooty (நீலகிரி மிஸ்ட்)

> **Perched 7,400 ft above the clouds amidst century-old eucalyptus groves and cascading tea estates on the Doddabetta slopes, Ooty, The Nilgiris.**

A large-scale, production-ready React web application featuring multi-lingual localization (English & தமிழ்), interactive 360° virtual chalet tours, 45-acre interactive topological estate explorer, multi-step booking & checkout engine with promo codes and printable boarding passes, in-villa dining food ordering tray, Ayurvedic spa scheduler, and 24/7 personal hill concierge butler desk.

---

## 🌟 Key Application Features

### 1. 🌐 Bilingual Support (English & தமிழ்)
- Seamless one-click language toggle in the header.
- Authentic Tamil translations for all villas, hill excursions, Badaga cuisine, spa therapies, and butler requests.

### 2. 🏡 Bespoke Chalets & Suites Showcase
- **6 Signature Living Sanctuaries:**
  - *The Cloud-Mist Glasshouse Chalet* (Floor-to-ceiling glass, floating bed, heated jacuzzi deck)
  - *Colonial Governor's Teakwood Suite* (1912 Victorian suite, British cast-iron fireplace, clawfoot tub)
  - *Pine Whispers Canopy Treehouse* (40 ft elevated suspension bridge, stargazing skylight)
  - *Emerald Estate Tea Planter's Cottage* (Direct step-out patio into organic tea slopes)
  - *Kurunji Royal 3-BHK Private Mountain Estate* (Private heated pool, private chef, helipad access)
  - *Misty Valley Cedar Attic Chalet* (Cozy timber attic, copper soaking tub, telescope)
- **Interactive 360° Panoramic Virtual Spin Tour** with degree rotation slider.
- Real-time stay duration & 12% luxury GST calculation.

### 3. 🗺️ 45-Acre Interactive Estate Explorer (Bird's Eye Map)
- Interactive topological map with pulsing radar beacons:
  - The Cloud Valley Heated Infinity Pool (32°C)
  - Century-Old Heritage Tea Gardens (45 acres)
  - The Glasshouse Chalet Enclave
  - Ayurveda Shala & Eucalyptus Steam
  - The Pine Bonfire Amphitheatre
  - Helipad & VIP Arrival Deck
- Interactive sound ambiance simulator (pine breeze & mountain birds).

### 4. 🚂 Curated Nilgiri Mountain Experiences
- UNESCO Heritage Nilgiri Mountain Toy Train Private Salon Car.
- Artisanal Tea Plucking & Single-Estate Cupping Masterclass.
- Candlelight Pine Forest Private Dinner with live violin.
- Dawn Cloud Peak Trek to Doddabetta Peak (8,652 ft).
- Starry Night Bonfire & Badaga Tribal BBQ.
- Instant slot & date reservation modal.

### 5. 🌿 Ayurvedic Sanctuary & Botanical Spa
- Nilgiri Eucalyptus Steam & Herbal Poultice.
- Royal Shirodhara & Abhyanga Synchronization Massage.
- Green Tea & Himalayan Salt Exfoliation.
- Sunrise Cloud Deck Pranayama & Yoga.
- Therapist selection (Female / Male / Specialist) appointment booking.

### 6. 🍽️ Estate Gastronomy, In-Villa Dining Tray & Table Reservation
- 3 Dining Concepts: *The Tea Nest Deck*, *Fire & Pine Mountain Grill*, and *Ooty Cocoa Bakehouse*.
- **In-Villa Dining Tray**: Add dishes to cart, adjust quantity, select delivery chalet, live 5% GST and butler room service calculation.
- **Table Reservation Engine**: Reserve tables with date, meal timing, guest count, and anniversary/celebration requests.

### 7. 💳 Multi-Step Checkout & Confirmation Engine
- **Step 1**: Review dates, nights, and add curated hill add-ons (Fireplace firewood bundle, Rose petal turndown, Coimbatore Airport SUV pickup, Ooty chocolate hamper).
- **Promo Coupon System**: Apply `OOTYMIST` or `NILGIRIS` for 15% discount or `WELCOME` for 10% discount.
- **Step 2**: Primary guest details, WhatsApp contact, and Government ID verification.
- **Step 3**: Payment simulation via UPI QR code, Credit/Debit Card, or "Pay at Resort".
- **Step 4**: Confetti celebration + Digital Boarding Pass / Printable Voucher with QR fast-pass code.

### 8. 🛎️ Active Reservations & 24/7 Hill Butler Concierge
- View confirmed bookings with reservation IDs.
- One-tap button requests: Fireplace logs, Hot cocoa with marshmallows, Extra blanket & heater, Cab dispatch, Morning tea tour guide.
- Live butler dispatch status feed.

### 9. ⛅ Live Ooty Mountain Climate Telemetry
- Real-time temperature (14°C), Mist index, Air Quality (16 AQI Pristine), Altitude (7,400 ft), Humidity, and 4-time forecast pill with night fireplace reminder.

## 🚀 How to Run Locally

```bash
# 1. Clone or navigate to the directory
cd e:\CODING\project\smart_project

# 2. Install dependencies (already installed)
npm install

# 3. Start development server
npm run dev

# 4. Open in browser:
# http://localhost:5173/
```

To build for production:
```bash
npm run build
```
